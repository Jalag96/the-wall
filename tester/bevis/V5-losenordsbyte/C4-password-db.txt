Vill vi byta lösenord till databasen så behöver vi göra det på två ställen - Secret och PostgreSQL.

1. Uppdatera Secret:

oc create secret generic wall-secret \
  --from-literal=DB_USER=walluser \
  --from-literal=DB_PASSWORD='LÖSENORD' \
  --dry-run=client -o yaml | oc apply -f -

Detta uppdaterar DB_PASSWORD i vår wall-secret. Webbappen använder detta värde för att ansluta till databasen.

2. Ändra lösenord i PostgreSQL:

Öppna shell-session i databaspodden:
oc exec -it deployment/wall-db -- bash

Ändra lösenord i PostgreSQL:
psql -U "$POSTGRESQL_USER" -d "$POSTGRESQL_DATABASE" ALTERNATIVT psql -U walluser -d walldb

När du är inne i PostgreSQL så kör du:
ALTER ROLE walluser WITH PASSWORD 'LÖSENORD';

3. Kör sedan: 
oc rollout restart deployment/wall-web

Detta kommer göra så att webbappen läser in nya Secret-värdena när en pod startar.

  Hur fungerar det?

- Kubernetes Secret lagrar lösenordet som webbappen använder.
- PostgreSQL har sitt eget lösenord för databasanvändaren.
- Båda måste ha samma lösenord för att anslutningen ska fungera.
- När webbappen startas om läser de nya Podarna in det uppdaterade lösenordet.
